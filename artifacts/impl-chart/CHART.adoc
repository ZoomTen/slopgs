= slopgs — MIDI Implementation Chart
:doctype: article
:toc:
:sectnums:

This document describes the MIDI behavior of the `slopgs` MIDI implementation,
an emulation of the Microsoft GS Wavetable Synth.

Updates along with `SPEC.adoc`.

[#s1]
== Receive data

In every byte pattern below, `n` is the MIDI channel nibble (`0`–`F`,
`0`=channel 1 … `F`=channel 16).


[#s1-1]
=== Channel Voice Message

`8n kk vv` — Note off::
* `kk` = note number (`00`–`7F`, 0–127)
* `vv` = release velocity (`00`–`7F`)
+
Received, **ignored**

`9n kk vv` — Note on::
* `kk` = note number (0–127)
* `vv` = velocity (`01`–`7F`, 1–127)
+
Sets loudness on a fixed curve
(perceptually, amplitude scales with the square of velocity/127)

`An kk vv` — Polyphonic Key Pressure (aftertouch)::
**Not recognized.** Received, no audible effect.

`Bn cc vv` — Control Change::
See <<scc,Control Change>>.

`Cn pp` — Program Change::
* `pp` = program number (`00`–`7F`, 0–127)
+
Combines with whatever Bank Select value is currently in
effect (<<scc,Control Change>>) to select an instrument.

`Dn vv` — Channel Pressure (aftertouch)::
**Not recognized.** Received, no audible effect.

`En ll mm` — Pitch Bend Change::
* `ll` = LSB
* `mm` = MSB
* Combine to a 14-bit value `mm` × 128 + `ll`.
* Center is `00 40` (8192, no bend)
* Applied continuously to every sounding note on the channel — a bend
arriving mid-note is heard *immediately*, not just on the next note. Range
is set by RPN0, default ±2 semitones (<<scc,Control Change>>).

[#scc]
=== Control Change

Only the controllers below are recognized. **Every other CC number
 is received and produces no effect, silently — never an error.**

`Bn 00 mm` — Bank Select MSB::
See Bank Select LSB.

`Bn 20 ll` — Bank Select LSB::
* Received and stored, but has **no effect until a GS Reset <<s1-4,System Exclusive>> has been
received at least once**.
* Takes effect on *next Program Change*, and _only_ after the SysEx.

`Bn 01 vv` — Modulation Wheel:: Recognized.

`Bn 06 mm` — Data Entry MSB::
See Data Entry LSB.

`Bn 26 ll` — Data Entry LSB::
Recognized only together with RPN 0/1/2 selection, below; meaningless on
their own.

`Bn 07 vv` — Channel Volume:: Recognized. Default `64` (100).

`Bn 0A vv` — Pan:: Recognized. Default `40` (64, center).

`Bn 0B vv` — Expression:: Recognized. Default `7F` (127).

`Bn 40 vv` — Hold 1 (Sustain)::
Recognized.
* `00`–`3F` = off
* `40`–`7F` = on (default)

`Bn 5B vv` — Effects 1 Depth (Reverb Send)::
**Not recognized.** Received w/o effect.

`Bn 5D vv` — Effects 3 Depth (Chorus Send)::
**Not recognized.** Received w/o effect.

`Bn 62 ll` — NRPN LSB::
See NRPN MSB.

`Bn 63 mm` — NRPN MSB::
Recognized only as "deselect the current RPN". **No NRPN parameter is ever addressable** — Data Entry sent after an NRPN
selection has no effect.
+
Sending either, with any value, immediately clears whatever RPN was previously selected to Null.


`Bn 64 ll` — RPN LSB::
See RPN MSB.

`Bn 65 mm` — RPN MSB::
Selects a Registered Parameter for the following Data Entry (CC6/CC38)
messages to target:
+
[options="header",cols="1,1,1"]
|===
| RPN (MSB,LSB) | Parameter | Applied
| `00 00`
| Pitch Bend Sensitivity. Data Entry MSB = semitones (0–24); LSB ignored. Default 2 semitones.
| Live — affects notes already sounding.
| `01 00`
| Channel Fine Tuning, ±100 cents (14-bit Data Entry).
| **Latched at Note On.** Changing it while a note is held does not retune that note.
| `02 00`
| Channel Coarse Tuning, ±64 semitones (Data Entry MSB only; LSB ignored).
| **Latched at Note On**, same as Fine Tuning.
| `7F 7F`
| Null (no parameter selected).
| —
| Others
| Any
| Stored, but *no effect*
|===


`Bn 78 00` — All Sound Off::
Recognized. Releases (does not hard-cut) every sounding note on the
channel, **bypassing** a held sustain pedal.

`Bn 79 00` — Reset All Controllers::
Recognized
Bank/Program and the RPN/NRPN selection are left untouched,
otherwise re-arms:
+
[options="header",cols="1,4"]
|===
|Parameter
|Value
|Channel Volume|100
|Pan|64 (center)
|Expression|127
|Pitch Bend|8192 (center)
|Modulation|0
|Sustain pedal|Released
|===

[WARNING]
--
Reset All Controllers (CC121), GS Reset, GM System On/Off and System Reset
(`FF`) *DO NOT reset* RPN0/1/2 or which RPN is currently selected — the
selection and tuning survive every reset path.
--

`Bn 7A 00` — Local Control::
**Not applicable** — `slopgs` has no local keyboard to disconnect.
Received, no effect.

`Bn 7B 00` — All Notes Off::
Recognized. Releases every sounding note on the channel, **honoring** a
held sustain pedal (notes under a held pedal stay held).

`Bn 7C 00` — Omni Mode Off::
See Omni Mode On.

`Bn 7D 00` — Omni Mode On::
**Not recognized.** Received, no mode change (<<s1-2,Channel Mode
Message>>).

`Bn 7E mm` — Mono Mode On (Poly Off)::
Recognized. Switches the channel to mono and silences every
currently-sounding note on it (implicit all-notes-off, per the MIDI
spec).
+
`mm` (requested mono voice count) is **ignored** — the channel
always behaves as if `mm`=1.

`Bn 7F 00` — Poly Mode On::
Recognized. Switches the channel to poly and silences every
currently-sounding note on it (implicit all-notes-off).

[#s1-2]
=== Channel Mode Message

Mode is only ever Omni Off (each channel answers exactly the Part(s)
mapped to it — see Basic Channel in the <<s3,chart>>, below). Omni On/Off
messages are received but never change this. Mono/Poly are switchable
per-channel via CC126/CC127 (<<scc,Control Change>>); a channel is
otherwise Poly by default.

[#s1-3]
=== System Common Message

Song Position Pointer, Song Select and Tune Request: **not recognized.**
`slopgs` renders a Standard MIDI File on its own clock and has no use for
sequencer-sync messages.

[#s1-4-rt]
=== System Real Time Message

`F8` Timing Clock, `FA` Start, `FB` Continue, `FC` Stop::
**Not recognized.**

`FE` Active Sensing::
**Not recognized** — received, no effect, and no 300 ms watchdog timeout
is armed by receiving it (irrelevant, since `slopgs` never transmits it
either).

`FF` Reset::
Recognized. Restores every power-on default:
+
[options="header",cols="1,4"]
|===
|Parameter
|Value
|Bank/Program|0 / 0 / 0
|Channel Volume|100
|Pan|64 (center)
|Expression|127
|Pitch Bend|8192 (center)
|Modulation|0
|Per-Part tuning grid|Flat (0)
|GS mode|Cleared (Bank Select inert until the next GS Reset)
|===

[WARNING]
--
Same exception as Reset All Controllers (CC121, <<scc,Control Change>>):
the currently-selected RPN/NRPN parameter and RPN0/1/2's tuned values
survive a Reset unchanged.
--

[#s1-4]
=== System Exclusive Message

Every recognized SysEx message below uses Roland's `DT1` ("Data set 1")
envelope, one parameter address per message:

[cols="1,2a"]
|===
| `F0 41 dev 42 12 aa bb cc dd`...`dd sum F7`
|
Roland GS-family message.

* `dev` = device ID — **not checked**
* `aa bb cc` = 21-bit parameter address.
* `dd...dd` = data bytes for that address.
* `sum` = checksum — **not checked**
| `F0 7E dev 09 01 F7`
| GM System On (Universal Non-Realtime).

`dev` not checked.
| `F0 7E dev 09 02 F7`
| GM System Off (Universal Non-Realtime).

`dev` not checked.
| `F0 7F dev 04 01 ll mm F7`
| Master Volume (Universal Realtime).

`dev` not checked. **Only `mm` (MSB) is used; `ll` (LSB) is never read.**
|===

Recognized `DT1` addresses (`aa bb cc`):

[options="header",cols="2,3,3a"]
|===
| Address | Parameter | Effect
| `40 00 7F`
| GS Reset
| Full device reset, **and** sets GS mode (Bank Select CC0/CC32 start taking effect).
| `40 1n 02`
| RCV CHANNEL (GS Mode)
| Remaps which incoming channel Part `n` listens to. Persists until a Reset.
| `40 1n 15`
| USE RHYTHM PART (GS Mode)
| Nonzero = Part `n` treats its Program Change as a drum-kit selection instead of a melodic instrument. Part 10 (channel 10) defaults to this.
| `40 1n` _any other_
| anything else in Roland's Patch-parameter address space for Part `n` (Reverb/Chorus Macro, Part Level, Pan, Pitch Key Shift, Velocity Sense, TVF/TVA modifiers, controller-destination depths, …)
| **Not individually implemented.**

Every one of these addresses is instead treated as a write into Part `n`'s 12-note Scale Tuning table (below), regardless of which parameter the address nominally names. A sequence intended to set, e.g., Reverb Macro or Part Level on real GS hardware will instead corrupt that Part's tuning.
| `40 1n 40`–`4B`
| Scale Tuning, one signed cents offset per semitone class (C…B), applied to Part `n`
| Recognized as such — it's the same fallthrough as the row above, landing on its real address.
|===

**Not recognized**:

* Reset to GS Standard Mode
* System Parameters (Master Tune, Master
Volume-via-`DT1`, Master Key-Shift, Master Pan — address family `40 00
00`–`06`)
* Display Data (address family `10 00 xx`, Model ID `45`)
* Drum Setup Parameters (address family `41 xx xx` — per-drum-instrument
key/level/pan/reverb/chorus edits)
* Bulk Dump (address families `48
xx xx`/`49 xx xx`)

Any `DT1` (or `RQ1`)
message with an address outside the table above, or with a manufacturer
ID other than `41`/`7E`/`7F`, is accepted and silently dropped.

[#s3]
== MIDI Implementation Chart

Basic Channel:: The MIDI channel(s) each of the 16 Parts answers to.

Mode:: Refers to the MIDI Mode messages (Omni On/Off, Mono/Poly).
`slopgs` always behaves as Omni Off; only the Mono/Poly half of Mode is
switchable, per channel.

Note Number / True Voice:: The range of note numbers accepted, and the
range actually reproduced. Note number 60 is middle C.

Velocity:: Whether Note On and Note Off messages' velocity byte affects
anything.

After Touch:: `Key's` = polyphonic (per-note) aftertouch, `Ch's` = channel
(monophonic) aftertouch.

Control Change:: See <<scc,Control Change>> for the full per-controller
list — this row just points there.

Program Change:: The program numbers a Program Change message can select
(raw message value — one less than the corresponding instrument number as
usually printed on an instrument list).

System Exclusive:: See <<s1-4,System Exclusive Message>> for the full
address table.

System Common, System Real Time:: Sequencer/drum-machine sync messages.
Not used, except Reset (`FF`).

[#s4]
== Specifications

Number of Parts:: 16.
Maximum Polyphony:: 54 voices (48 sustained under continuous overload)
+
An
automatic accelerated-release policy engages once demand exceeds the
pool, freeing voices faster than a plain steal-oldest policy would).
Effects:: None.
Wavetable source:: A DLS-1 sample collection. (Depicted here is the standard `gm.dls`.)
Output format:: 22050 Hz, stereo, 16-bit signed PCM.
